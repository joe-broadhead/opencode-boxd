# Changelog

## [0.0.0] - unreleased

The first release under `we-the-rebel-alliance`, rebuilt greenfield on OpenCode 2.4.1 and plugin-contract v0.

- One `contract.register` call wires every method through the agent tool, Code Mode and one RPC id `boxd`. The copied
  tools-RPC transport, the legacy declaration and the copied kit are gone.
- The `capabilities` manifest replaces the legacy package keys: 14 methods with a class and provider operations, two
  sources (`boxd.works` events and `boxd.works.list` snapshot), the `changed` bus event, and the local account.
- `events_list` is a tool too (`boxd_events_list`), declared once with its source.
- Accounts are local: one account, `default`, the machine's identity; no sign-in input on any method.
- Access rules are generated by the contract's `access` module at `all`, `ask-changes` and `read-only`; `exec` asks even
  at `all`.
- Every write emits `changed`.
- The v0 ledger import and the fields it read are removed; the ledger starts empty.
- The end-of-turn idle hook and the `/boxd-cleanup` command and its TUI view are removed. The `/boxd` report keeps the
  cost, the fleet and the one next step; nothing runs per request.
- Docs, `AGENTS.md` and the `boxd-sessions` skill are written fresh; the generated sections come from
  `plugin-kit docs`.
- Tests: unit, the contract's conformance with the one local account, the host proof on 2.4.1, and pack.
